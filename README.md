My project mainly involves a player controlling a fighter jet to defeat enemies. Each time an enemy is defeated, a new one will be generated and one point will be added. There are two enemies with different hp levels, 2 and 3 respectively. Every 10, a boss will spawn at a random position. The boss's hp increases with the score. After defeating the boss, a reward will be generated. This reward can increase the player's laser firing speed. Victory is achieved when the score reaches 50 points, but the game ends when the enemy reaches the bottom

[Mac]
1. Open `Finder` and navigate to the Applications folder.
2. Right-click on the Greenfoot app and select `Show Package Contents`.
3. In the opened folder, go to `Contents -> Resources -> Java` and find the `greenfoot.jar` file.
4. Copy this `greenfoot.jar` to the `/lib` Folder in this project.

[Windows]
1. Open `File Explorer` and navigate to `C:\Program Files\Greenfoot` and locate the `greenfoot.jar` file.
2. Copy this `greenfoot.jar` to the `\lib` Folder in this project.
